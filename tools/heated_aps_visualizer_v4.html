Both arms are built from up to 8 plateaus joined by cosine tapers (input and output tapers included). The differential phase Δφ(λ) = ∫ (2π/λ)[neff,top(x,λ) − neff,bot(x,λ)] dx is integrated straight through the tapers — they are not bolted on afterwards — and compared against the broadband nulling target Δφ = π. Effective indices come from the embedded StraightWaveguide_neff_long table, bilinearly interpolated in width and wavelength, never extrapolated.

What the model does

  • Geometry. The device is a span list: input taper → plateau 1 → taper → plateau 2 → … → output taper → trim region. Every taper uses w(s) = w0 + (w1−w0)·[0.5 − 0.5 cos(πs)], s∈[0,1].
  • Taper integration is exact. For a fixed wavelength the interpolated neff(w) is piecewise linear in w, so each taper is split at the width-grid crossings and integrated in closed form. Changing the taper length therefore cannot produce a sampling artifact — there is no x-sampling grid at all.
  • Heater (toy model). neff,heated = neff,base(w,λ) + (dneff/dT)·ΔT. dneff/dT is a single adjustable number with no width, wavelength or temperature dependence — a placeholder until measured or simulated data replaces it.
  • ΔT across a taper blends with the same cosine profile as the width, from the neighbouring plateau value (0 outside the segmented region). Nothing is discontinuous.
  • Target. φerror(λ) = wrap[Δφ(λ) − π] into (−180°, 180°].
  • Ideal phase-only null. I/Imax = sin²(φerror/2). Perfectly balanced amplitudes are assumed, so this is a phase-error floor only, not a device null depth — no loss imbalance, no splitter error, no polarisation.

Intuition this tool is for

  • A heater adds roughly Δφ ≈ 2π·(dneff/dT)·ΔT·L/λ, so its phase contribution scales as 1/λ. Fixing the error at 1550 nm with one heater leaves a tilt across the band — switch to Raw Δφ/π and watch it.
  • A width difference contributes (2π/λ)·Δneff(λ)·L. Because Δneff is itself wavelength dependent and that dependence varies with width, several segments with different width pairs can trade off constant offset, slope and curvature.
  • Achromatic Δφ = π needs the differential optical path to track λ/2, not to be constant. That is the whole difficulty.

Upgrade path left open

The heater lives behind a single HeaterModel object that maps commanded settings to a per-region ΔT and then to an index shift. Swapping in P=V²/R, ΔT=ηP, a crosstalk matrix ΔTactual=C·ΔTcmd, or a width/wavelength dependent dneff/dT only touches that object, not the geometry or phase integrator.
